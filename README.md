# 中药药对协同潜力筛选平台

面向科研人员的网络药理学证据看板。保留原有七个章节，当前仅展示新分阶段公式的筛选结果，并保存原始文件、参数、逐关计算和对接证据。线上是只读结果预览，不是已接通远程计算的服务。

本地网页：<http://localhost:8510>

公开网页：<https://uc-herb-pair-platform.streamlit.app/?embed=true>。

## 已验证基准任务（2026-09-27）

- 疾病：溃疡性结肠炎（UC）。
- 候选：24味中药，不限制药食同源。
- 新漏斗：276组 → 靶点初筛Top30 → PPI复筛Top15 → 通路精筛Top10 → 锁定Top3。
- 疾病交集靶点：93个。
- STRING阈值0.4；复用输入基因及参数一致的DAVID原始快照，不复用旧排名。
- 新Top3为甘草＋马齿苋、甘草＋黄芪、甘草＋石榴皮；前两名同分，名称次序不表示生物学优劣。
- 15组通路精筛均为6条共同核心通路、0条互补核心通路，因此该关没有进一步拉开排名。
- 三组候选各药材最高优先级成分均为槲皮素，共享**一个独立化学对接任务**，不能视为三次独立药对协同验证。
- 槲皮素–PTGS2/5IKR结合能为−7.912 kcal/mol；核对受体、网格、配体和参数后明确复用已有Vina结果，本轮新增化学对接任务数为0。
- PTGS2/5IKR共晶配体固定受体坐标回对接RMSD为1.8448 Å（未对配体叠合），通过≤2.0 Å质控。历史配体叠合RMSD不作为本轮质控值。

网页第七章可查看本轮锁定候选、成分归属、共享任务、PDB与PubChem编号、回对接原子映射、参数、复用记录、失败原因和原始结构文件。所有排名来源及产物指纹不一致时停止展示旧榜单。

本轮核心/重要/普通靶点按511个已选疾病基因的关联分数分档，最高10%为核心、随后20%为重要，同分同级；10条KEGG通路预先固定。这些是项目操作性定义，不是数据库官方认定的疾病核心名单。本轮仍沿用原OB/DL输入，没有新增Caco-2筛选。

## 通用任务入口的当前状态

新公式目前只配置了UC基准任务，**本地新建任务按钮暂时禁用**，避免误调用旧算法或将UC核心通路套给其他疾病。原有通用数据获取和对接模块保留，尚未与新公式整合；线上也未接通个人电脑计算后台。以下是此前已实现的渠道能力，不表示新算法已经适用于任意疾病：

- Open Targets官方API：全自动获取疾病靶点，不需要登录。
- GeneCards：官方没有公开OAuth且禁止自动抓取，因此采用“人工登录导出后上传”的合规模式。
- TCMSP：自动抓取成分和靶点；缺失药材不会被伪装成“没有成分”，而是明确报出证据缺口。
- HERB 2.0 / ETCM 2.0：读取完整活性靶点后，重新与本次疾病取交集，不复用UC专属交集。
- DAVID、STRING、Cytoscape：按任务目录保存输入、响应和结果。
- 分子对接：优先使用已验证结构；陌生靶点自动通过UniProt和RCSB寻找实验结构、共晶配体和Grid Box，并先做回对接。

通用结构发现已用注册表外的TNF实测：系统自动尝试多个PDB，前两项受体准备失败、6X82回对接RMSD 3.6635 Å未通过，随后切换到6X81并以RMSD 1.1185 Å通过。失败记录被保留，没有强行判定为成功。

## 结果边界

- 系统输出的是实验前“协同潜力排名”，不是临床药方。
- 靶点、PPI、富集和分子对接不能单独证明“1+1＞2”。
- 真正协同仍需单药A、单药B、联合AB及正式协同模型实验确认。
- 任意新任务都可能因数据库未收录、官方接口暂时不可用、缺少合格PDB结构或回对接不通过而停止；系统应报告明确终态，不伪造Top3。

## 项目结构

```text
app.py / src/                    网页、任务创建和证据展示
config/tasks/                    每个任务的冻结输入与流水线配置
data/formal_inputs/              数据库导出和标准化输入
data/formal_analysis/            交集、PPI、DAVID、排名和对接结果
data/channel_tests/              数据渠道与通用结构发现测试证据
runs/                            步骤状态、日志、报告、快照和哈希
scripts/                         可复现科研流水线
tools/vina/                      本地AutoDock Vina执行文件
```
